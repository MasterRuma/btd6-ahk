### Primary Only (Fast Track + Double Cash)
- Strategy: `OffTheCoastFTDC()` calls the shared `GeneralPrimaryFTDC()` function.
- Uses the currently selected hero.
- Dart 1 (564, 801): 024 -> 025 -> Paragon (bottom path, no extra cash investment).
- Boomer 1 (241, 533): 402 -> 502.
- Hero (325, 122).
- Dart 2 (112, 505): 502.
- Dart 3 (292, 464): 050.
- Set `mapSelect=off_the_coast`, `mapCategory=advanced`, and `difficulty=primary` in `config.ini`.
- Set `enableFreeplayInsta=true` to continue into freeplay after the 4th-tier upgrades and execute the remaining sequence.
- Game completion has not been verified.
